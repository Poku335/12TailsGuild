# 12Tails — AngelaZ Hub

เว็บไซต์ศูนย์รวมชุมชนกิลด์ **AngelaZ** สำหรับเกม 12Tails Online  
รองรับการจัดการข้อมูลกิลด์ ระบบคลัง ตลาด และ receipt ข้อมูลต่างๆ ในเกม

---

## Homepage

![Homepage](AGNY/1.png)

หน้าหลักของกิลด์ แสดงข้อมูลภาพรวม เช่น จำนวนสมาชิก จำนวน Party Posts และ shortcut ไปยังเมนูต่างๆ

---

## Receipt สำหรับข้อมูลต่างๆในเกม

![Receipt](AGNY/2.png)

รวบรวมข้อมูลสำคัญในเกมในรูปแบบการ์ด เช่น ตาราง Boss ตาราง อารีน่า  
สมาชิกสามารถเพิ่ม/แก้ไขข้อมูลได้ตามสิทธิ์

---

## หน้ากิลด์ สำหรับแสดงของที่อยู่ในคลังกิลด์

![Guild Storage](AGNY/3.png)

แสดง inventory ของแต่ละคลังกิลด์พร้อม Export Excel และระบบค้นหาไอเทม

---

## ระบบ เบิก/ซื้อของ คลังกิลด์

![Guild Storage Request](AGNY/4.png)

ระบบสำหรับสมาชิกขอเบิกหรือซื้อของจากคลังกิลด์ Admin สามารถยืนยันหรือลบคำขอได้  
รองรับประเภทไอเทม: เบิก ซื้อ พร้อมระบุจำนวน

---

## Features

- **Home** — ข้อมูลภาพรวมกิลด์
- **Info** — ประกาศและข่าวสาร
- **Party** — ระบบจัดปาร์ตี้
- **Market** — ตลาดซื้อขายของกิลด์
- **Receipt** — ข้อมูลและตารางเกม
- **Guild Storage** — ระบบคลังและเบิกของ

## Tech Stack

- [Next.js](https://nextjs.org/) (App Router)
- TypeScript
- Tailwind CSS
- Discord OAuth
